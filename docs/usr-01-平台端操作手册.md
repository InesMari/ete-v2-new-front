# 平台端操作手册（usr-01）

> **适用对象**：平台端用户 —— 运营/调度、仓储管理、财务、采购、资产、人力资源、系统管理员等。
> **本篇解决**：各业务域的高频操作（建单、派车、入库、盘点、账单、报表等）。
> **说明**：标注"AI 可查"= AI 能实时调接口查数据；标注"页面操作"= 需在平台端页面完成，AI 只给指引。接口权威定义见 [api-00-接口清单.md](./api-00-接口清单.md)。

---

## 一、登录与主框架

### Q1：怎么登录平台端？
**页面操作**：浏览器访问平台端地址 → 登录页输入账号密码（或手机号 + 短信验证码）→ 验证通过进入工作台。
- 连续输错会要求**图形验证码**；忘记密码可走短信找回。
- 多公司账号登录后先**选择公司**再进入。

### Q2：登录后页面结构？
**答**：左侧是功能菜单树（按你的权限显示），顶部有搜索、待办角标、用户菜单（修改密码/退出）。打开的功能以**标签页**形式展示，可关闭/刷新/拖拽。

### Q3：为什么我看到的菜单比别人少？
**答**：菜单/按钮由后台权限控制（每个账号绑定角色 → 权限点）。看不到即无权限，需联系管理员开通。

### Q4：登录一段时间后自动退出？
**答**：会话默认 4 小时无操作过期；"记住登录"可保持 7 天。建议用完后主动退出。

## 二、订单管理

### Q5：怎么新建一笔订单？
**页面操作**：订单管理 → 新增订单，填写：
- 发货地址、收货地址（支持多装多卸）、业务类型、装货时间；
- 货物信息（名称、重量、体积）、车型车长、数量；
- 结算方式、是否含税、结算价、回单要求、备注。

**AI 可协助**：查客户列表、静态字典（车型/业务类型）；订单列表查询用 `orderTF.queryOrderInfoList` 等（AI 可查）。

### Q6：订单怎么修改/复制/取消？
**页面操作**：订单管理 → 选中订单：
- **修改**：编辑后保存（只能改允许修改的字段，已派车/已完成的订单部分字段锁定）；
- **复制**：复制为新订单再调整；
- **取消**：取消订单（已进入派车/运输的订单不可直接取消）。

### Q7：怎么把订单派给车辆？
**页面操作**：订单管理 → 派车（或调度中心）：选择订单 → 新增派车单 → 选车辆、司机、预计时间 → 提交。派车后订单进入"待出车"。

### Q8：订单状态怎么看？
**AI 可查**：按订单号/车牌/客户/时间查询订单列表，看状态字段；运单详情里有**操作日志时间线**（下单 → 派车 → 出车 → 到达 → 签收），AI 可帮你梳理进度。

### Q9：回单在哪看？
**页面操作**：回单管理 → 按订单/运单查询回单（签收凭证图片），可下载/预览。

### Q10：订单异常了怎么办？
**页面操作**：异常订单会进入异常跟踪（见"异常与日志"模块），可查看异常原因、处理记录；处理完成后再继续流转。

## 三、仓储管理

### Q11：怎么预约车辆到库？
**页面操作**：仓储 → 预约管理 → 新增预约：填仓库、车牌号、司机、预计到库时间、关联订单。预约后会出现在**预约大屏**，收货口按预约安排收货。

### Q12：入库怎么做？
**页面操作**：收货/入库 → 按预约或直接入库：选择仓库、货物、数量 → 生成入库单 → 货物进入库存。入库单可打印/查看二维码储位。

### Q13：库存怎么查？
**AI 可查**：按物料维度（`queryStockMaterialPage`）或储位维度（`queryStockStoragePage`）查库存，可指定仓库。

### Q14：货物怎么分配储位？
**页面操作**：分配储位 → 选择货物 → 指定储位/推荐储位 → 确认分配。分配后物料库存明细中可看到储位信息。

### Q15：盘点怎么做？
**页面操作**：盘点管理 → 新建盘点单 → 选择仓库/储位 → 录入实盘数量 → 对比账面 → 盈亏处理 → 审核生效。

### Q16：出库怎么做？
**页面操作**：出库单管理 → 新建出库单（关联订单/配送任务）→ 出库操作 → 货物出库。出库后库存扣减，生成配送运单（可在配送大屏看到）。

### Q17：温湿度传感器数据在哪看？
**页面操作**：仓储 → 传感器管理 → 查看各传感器实时/历史数据（温湿度），超限会有记录与打印。

## 四、财务管理

### Q18：客户账单怎么生成/查看？
**页面操作**：财务中心 → 客户账单：可按客户/时间查询账单，查看费用明细（仓储费、配送费、其他费用），支持生成账单、核对、确认状态跟踪。

### Q19：供应商账单怎么处理？
**页面操作**：供应商账单 → 查看应付费用 → 核对 → 确认/结算（关联供应商付款）。

### Q20：标准成本是什么？
**答**：按线路/产品/仓库配置的**参考成本**，用于报价与成本核算。在财务 → 标准成本中维护，AI 可查配置明细（`fc*TF` 相关接口）。

### Q21：发票怎么开？
**页面操作**：发票管理 → 新增发票（客户、金额、税点、含税/不含税）→ 提交。开票与账单关联。

### Q22：零星费用怎么记？
**页面操作**：零星费用管理 → 新增费用（类型、金额、归属客户/项目）→ 提交，后续并入账单。

### Q23：货主不确认账单怎么办？
**答**：货主端"未确认账单"列表需要货主点击**确认**。平台可联系货主提醒；AI 可查未确认账单列表帮你跟进。

## 五、资源管理

### Q24：车辆档案怎么维护？
**页面操作**：资源管理 → 车辆管理：新增/编辑车辆（车牌、车型、车长、所属组织、状态）、停用/启用。

### Q25：司机档案怎么维护？
**页面操作**：司机管理：新增/编辑司机（姓名、手机号、证件、所属车队、状态）。

### Q26：运力计划怎么安排？
**页面操作**：运力计划 → 按日期/线路安排可用车辆与司机，形成计划运力，调度派车时优先匹配计划运力。

### Q27：车辆实时位置怎么看？
**页面操作**：车辆监控 → 地图实时显示车辆位置（百度地图），点车辆看定位时间与最新位置；可按车牌过滤。大屏投放见 [web-21-大屏看板](./web-21-大屏看板.md)。

## 六、采购管理

### Q28：怎么发起采购申请？
**页面操作**：采购管理 → 采购申请 → 新增：填品名、数量、需求部门、期望到货日期 → 提交。

### Q29：采购怎么审批？
**页面操作**：审批列表 → 查看申请 → 通过/驳回。驳回需填写原因，申请人修改后重新提交。

### Q30：采购领用怎么做？
**页面操作**：领用管理 → 新增领用（关联采购入库/资产）→ 确认领用人。

### Q31：固定资产怎么调拨？
**页面操作**：资产调拨 → 选择资产 → 调入部门/组织 → 提交，资产归属变更。

---

## 七、数据报表

### Q32：报表在哪看？
**页面操作**：数据报表 → 统计报表：订单量、运量、仓储出入库、财务应收应付等报表，支持时间/组织筛选。

### Q33：报表能导出吗？
**答**：支持导出 Excel（页面右上角导出按钮）；AI 可协助查报表数据并汇总说明。

### Q34：看板大屏怎么投？
**页面操作**：大屏（订单/预约/仓储中心/今日计划/配送/车辆监控）通过独立 URL 直接访问，浏览器按 F11 全屏投放即可。详见 [web-21-大屏看板](./web-21-大屏看板.md)。

---

## 八、业务协同

### Q35：协同调度是什么？
**答**：多组织/多仓库间的订单协同派车（协同调度、协同仓配），一个订单可由协同方共同完成运输/仓储环节。在业务协同模块发起与处理。

---

## 九、基础数据与系统管理

### Q36：字典/枚举怎么维护？
**页面操作**：基础数据 → 字典管理：新增/修改字典项（业务类型、车型、结算方式等），修改后**刷新缓存**生效。

### Q37：组织和员工怎么维护？
**页面操作**：组织管理（部门树）、员工管理（新增/编辑员工、绑定账号）、岗位管理。

### Q38：权限和角色怎么分配？
**页面操作**：权限管理 → 角色管理：创建角色 → 分配权限实体（菜单/按钮）→ 用户绑定角色。新增用户：用户管理 → 新增（手机号、姓名、角色、组织）。

### Q39：改了配置不生效怎么办？
**答**：先在"缓存刷新"刷新对应缓存；仍无效检查是否缓存到旧值。AI 可协助触发刷新。

### Q40：操作日志去哪看？
**页面操作**：系统 → 操作日志/系统日志：按用户/时间/模块查询操作记录，用于审计与排障。
