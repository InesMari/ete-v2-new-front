## 项目概要

| 项目 | 说明 |
|------|------|
| 项目名称 | EDB 企业数字化管理平台（ETE） |
| 技术栈 | Vue 2.6.10 + Vue CLI 4 + Element UI 2.15 + Vant 2.12 |
| 核心业务 | 订单管理、仓储管理、财务管理、资源管理、采购管理、客户/供应商管理、数据报表 |
| 部署形态 | 平台端 (pt) + 货主端 (hz) + 易迁易大学 (edu) + 微信公众号 (wx) |
| API 模式 | Spring Bean RPC（beanName + methodName，经 `common.postUrl` 调用） |
| 安全机制 | RSA 加密 + Token 校验 + v-entity 权限指令 + http→https 跳转 |

## 使用建议

1. **Dify 导入**：将整个 `docs/` 文件夹上传到 Dify 知识库，Dify 会自动解析 Markdown 文件
2. **搜索优化**：文档标题使用 `# 核心业务 — 模块名` 格式，便于 Dify 按模块检索
3. **API 查询**：当用户询问"如何调用XX接口"时，可检索 `api-00-接口清单.md`（事实源）与 API 接口索引文档
4. **架构理解**：当用户询问"XX功能在哪里"时，可检索项目总览和业务模块文档
5. **接口清单更新**：`api-00-接口清单.md` 由 `docs/tools/extract-api.js` 生成，接口变更后执行 `node docs/tools/extract-api.js` 重新生成
6. **页面索引更新**：平台端增删改页面后，执行 `node docs/tools/extract-pages.js` 刷新 `docs/pages-index.json`；脚本不会覆盖已人工精修（status=done）页面的 name/description/keywords 等字段，详见 [26-页面索引](./web-26-页面索引.md)
