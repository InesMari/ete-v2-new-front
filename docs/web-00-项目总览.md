## 1. 项目概述

**EDB 企业数字化管理平台（ETE）** 是一套面向物流供应链场景的综合企业数字化管理系统。平台以"订单—仓储—运输—财务"为核心业务闭环，提供从客户下单、调度派车、仓储收发存、运输在途、财务结算到数据报表的全链路数字化管理能力，并支持多租户（平台/货主/司机/学员）独立门户访问。

系统采用 **多租户架构**，按访问入口划分为五个端：

| 端 | 目录 | 定位 |
|----|------|------|
| 平台端 | `src/page/pt` | 平台运营方使用，覆盖全部核心业务域（订单/仓储/财务/采购/资源等） |
| 货主端 | `src/page/hz` | 货主使用，支持下单、订单跟踪、仓储查询、财务对账、大屏 |
| 易迁易大学 | `src/page/edu` | 在线学习平台（管理员/学员），独立主题色 |
| 微信公众号 | `src/page/wx` | 微信 H5 下单入口 |
| 演示/其他 | `src/page/demo`、`src/page/sh` | 演示页面与其他端 |

## 5. 核心设计机制

### 5.1 动态组件切换（App.vue）

ETE 不使用传统多路由嵌套，而是通过 `App.vue` 根据 URL 识别租户端，用 Vuex 的 `componentName` 状态 + `<component :is="componentName">` 动态挂载入口组件（登录页/主框架/大屏等）。见 [web-04-状态管理与路由.md](./web-04-状态管理与路由.md)。

### 5.2 页面打开机制（myTab 动态路由）

主框架内使用 `myTab` 标签页组件：调用 `$refs.myTab.openTab(item)` 时，组件内部通过 `router.addRoute` 动态注册路由（路径 `urlPathName_urlId`，组件由 `import('@/page' + item.urlPath)` 懒加载），再 `router.push` 跳转。实现"单页应用 + 多标签页"体验。

### 5.3 RPC 风格 API 调用

后端接口以 `beanName + methodName` 标识（Spring 服务方法），前端统一通过 `common.postUrl(beanName, methodName, params, successFn, errorFn, httpMethod, shadow)` 调用，见 [web-01-开发规范.md](./web-01-开发规范.md)。

### 5.4 权限控制（v-entity）

页面元素权限通过自定义指令 `v-entity="'权限码'"` 控制，根据本地存储的 `entityIds` 判断是否渲染，见 [web-01-开发规范.md](./web-01-开发规范.md)。

### 5.5 安全机制

- **RSA 加密**：`main.js` 注册 `$getRsaCode` 方法，敏感参数使用后端公钥加密
- **Token**：登录后存储 token，请求携带校验；iframe 通过 postMessage 传递 token（限制来源域名）
- **HTTPS 跳转**：生产环境自动将 http 请求跳转 https
- **过期校验**：token 变更/过期时通过 postMessage 通知父页面重新登录

## 6. 构建与配置

### 6.1 代理配置（vue.config.js）

```js
// devServer 代理：开发环境 /api 前缀转发至测试后端
'/api': {
    target: 'http://183.6.76.4:38010',
    changeOrigin: true

```

### 6.2 全局 SCSS 注入

`vue.config.js` 的 `css.loaderOptions.scss.prependData` 自动注入全局变量与 mixin，页面可直接使用 `_variable.scss` 中定义的颜色/间距变量。

### 6.3 构建输出

- 生产环境关闭 sourceMap，打包产物含时间戳版本
- 多页面入口按需构建
