## 三、通用业务规则（所有端适用）

### 3.1 登录

- **平台端**：账号密码 或 短信验证码登录；密码经加密传输；连续输错可能触发图形验证码。
- **货主端**：货主账号登录（`hz` 入口）；多公司账号登录后需**选择公司**再进入。
- **大学端**：学员/管理员两种模式分别登录，管理员无管理权限时无法进入管理后台。
- **微信端**：免登录，凭二维码进入。
- 记住登录有效期 7 天；会话 4 小时无操作需重新登录。

### 3.2 订单状态主线

```
待调度 → 已派车（待出车） → 出车运输（已出车） → 到达卸货 → 签收完成 → 回单
                     ↘ 异常（异常单需跟踪处理）
```

订单每一步都有**操作日志**，可在订单/运单详情中查看时间线。

### 3.3 仓储主线

```
车辆预约到库 → 收货/入库 → 分配储位（库存可查） → 出库计划 → 出库/配送 → 盘点
```

### 3.4 财务主线

```
费用产生（仓储/运输/杂费） → 账单生成 → 货主确认 → 开票/结算 → 收入确认
```

- 货主端未确认的账单需货主**确认**后平台才能继续开票结算。
- 异常/驳回的单据需修改后**重新提交**。

### 3.5 权限

每个账号的菜单、按钮、数据范围由后台权限点（`v-entity`）控制。**看不到某个菜单/按钮 = 该账号没有对应权限**，不是系统缺失。

## 四、向 AI 助手提问的正确姿势

1. **说人话、说清对象和时间**：如"查一下这批货的订单到哪了""上个月还有多少未确认的账单"。
2. **AI 能直接查的**：订单/库存/账单/报表等**查询类**问题，AI 会实时查系统数据给你答案。
3. **AI 只给操作指引的**：新增/修改/删除/审核等**写操作**，AI 一般只告诉你"去哪个菜单、怎么点"，不会代替你执行（除非系统明确允许）。
4. **问不出结果时**：可能是数据不在你的权限范围（组织/仓库）、时间范围不对，或状态已变化，可换个问法再试。

## 六、常见名词速查

| 名词 | 含义 |
|------|------|
| 订单 | 货主委托运输的业务单据（含装货/卸货、货物、车型、结算方式） |
| 派车单 | 调度把车辆+司机指派给订单的派车记录 |
| 运单 | 实际执行运输的单据，关联订单与派车 |
| 回单 | 收货方签收后的凭证（司机/收货方确认签收） |
| 预约 | 车辆到库前在系统预约到库时间，方便仓库安排收货口 |
| 入库单/出库单 | 货物进出仓库的业务单据 |
| 库存分配 | 货物入库后分配到具体储位（物料/储位两个维度可查） |
| 账单 | 按客户/供应商维度汇总的费用单据（仓储费、配送费、其他费用） |
| 学分 | 大学平台学员完成课程/考试获得的学分 |
| 权限点 | 后台配置的菜单/按钮权限，用 `v-entity` 控制前端显示 |
