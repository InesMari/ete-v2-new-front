# 易迁易大学操作手册（usr-03）

> **适用对象**：易迁易大学（edu）学员与管理员 —— 在线学习、考试、图书与班级管理。
> **本篇解决**：学员怎么登录学习考试、管理员怎么管理课程/考试/图书/班级/学员/首页。
> **说明**：接口权威定义见 [api-00-接口清单.md](./api-00-接口清单.md)；大学端技术细节见 [web-23-易迁易大学.md](./web-23-易迁易大学.md)。

---

## 一、登录

### Q1：大学怎么登录？
**页面操作**：访问大学端地址（`edu` 入口）→ 登录页有**两个 Tab**：
- **学员登录**：学员账号（手机号+密码 或 短信验证码）；
- **管理员登录**：管理员账号。

登录后学员进入**门户首页**，管理员进入**管理后台**。

### Q2：忘记密码怎么办？
**页面操作**：登录页 → 忘记密码 → 手机号短信验证码验证 → 设置新密码。

### Q3：管理员登录后进不了管理后台？
**答**：账号无管理权限（`noAuthHome`）时会提示无法进入管理首页，请联系管理员开通权限。

## 二、学员端

### Q4：门户首页能看到什么？
**答**：
- 顶部**横幅**（公告/活动轮播）；
- **课程分类导航**（横向菜单，支持二级分类）；
- **热门课程**推荐；
- **学习排名**（部门/学分排行）；
- **课程列表**（按分类浏览全部课程）。

未登录也可浏览门户，登录后进入个人学习。

### Q5：怎么选课学习？
**页面操作**：门户 → 课程列表/课程详情 → 进入课程 → 开始学习（看章节资料）。学习进度会自动上报（学习时长/完成章节）。

### Q6：怎么查看我的学习进度？
**页面操作**：个人中心 → 我的课程 / 最近学习：查看已完成、进行中的课程与进度。**AI 可查**：最近学习课程、学习时长。

### Q7：怎么参加考试？
**页面操作**：个人中心 → 我的考试/在线考试 → 选择考试 → 作答（单选/多选/判断/简答）→ 提交。
- 客观题自动判分；含**简答题**的考试需老师批阅后出分。

### Q8：考试成绩和学分怎么看？
**页面操作**：个人中心 → 考试记录：查看每次考试成绩与时间；**学分**：查看累计学分数据。**AI 可查**：考试记录、学分明细。

### Q9：电子图书怎么看？
**页面操作**：门户 → 图书详情：浏览电子书（书名、封面、简介、章节），在线上阅读。

### Q10：怎么退出登录？
**页面操作**：右上角用户菜单 → 注销，退出后回到登录页。

## 三、管理端

### Q11：管理后台首页看什么？
**页面操作**：进入管理后台 → 首页：课程数、学员数、考试数等统计概览。

### Q12：怎么新增课程？
**页面操作**：课程管理 → 新增课程：
- 课程标题、封面、分类；
- 可选**岗位范围**（哪些岗位可见）；
- 指派班级（哪些班级学员可选/必修）；
- 上传课程资料（视频/文档）。

保存后可对课程**置顶**、修改、删除。

### Q13：怎么给课程安排考试？
**页面操作**：课程管理 → 选择课程 → 新增考试：关联课程 → 组卷（单选/多选/判断/简答）→ 设置考试时长 → 发布。删除课程会连带删除其考试，请注意。

### Q14：怎么看学员的学习记录？
**页面操作**：课程管理 → 学习记录：按课程/学员查学习进度（学时、完成章节）。

### Q15：怎么查看/批阅成绩？
**页面操作**：
- 成绩查看：按课程/班级查考试成绩；
- **简答题批阅**：学员管理 → 简答题批阅 → 打开学员试卷 → 打分 → 提交。批阅后学员才能看到完整成绩。

### Q16：怎么管理学员？
**页面操作**：学员管理 → 学员列表：查看学员信息与学分明细；按学号/姓名/班级查询。

### Q17：怎么管理班级？
**页面操作**：班级管理（班级树）：新增/编辑/删除班级（按组织架构），用于课程指派与学员归班。

### Q18：怎么维护电子图书库？
**页面操作**：图书管理 → 新增/编辑图书（书名、封面、附件、所属组织）→ 发布后学员端可见。

### Q19：怎么配置门户首页？
**页面操作**：首页管理 → 配置：横幅（轮播图）、热门课程、公告位等，保存后学员端即时生效。

### Q20：系统日志在哪看？
**页面操作**：系统日志：按用户/时间/操作查询管理端操作记录，用于审计。

### Q21：管理端退出/快捷键？
**页面操作**：右上角用户菜单 → 注销；管理后台支持多标签页操作，标签可关闭/刷新。

## 五、常见误区

| 误区 | 正确做法 |
|------|----------|
| 学员账号登录后找管理菜单 | 学员端无管理菜单；管理需用管理员账号 |
| 组卷后学员马上能考 | 需发布/指派班级后才可见 |
| 简答题交卷就出分 | 需管理员批阅后才出完整成绩 |
| 删除课程只删课程 | 会连带删除该课程的考试，请谨慎 |
| 在学员端维护图书/首页 | 图书、首页配置都在管理端 |
