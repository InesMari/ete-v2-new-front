## 一、微信端下单

### Q1：微信怎么下单？
**页面操作**：微信扫码（或点击二维码链接）→ 打开下单页面，按**四步**操作：

| 步骤 | 标题 | 你要做什么 |
|------|------|-----------|
| 第 1 步 | 去下单 | 确认装货地址、卸货地址，选业务类型和装货时间 → 下一步 |
| 第 2 步 | 地址 | 新增/编辑地址：可**粘贴一段文字自动识别**（如"广东省深圳市南山区XX路XX号 张三 138xxxx"），或手动选省市区+填详细地址+联系人+电话 |
| 第 3 步 | 完善信息 | 填货物名称、总重量/体积、车长车型、结算方式、结算价、是否要回单、是否含税（含税需填公司名称）、订单备注 → 提交 |
| 第 4 步 | 完成 | 提交成功，等平台调度派车 |

### Q2：二维码失效了怎么办？
**页面操作**：页面提示"该二维码已失效"时，需联系发放二维码的业务人员重新生成二维码。

### Q3：地址怎么快速填？
**页面操作**：在第 2 步地址输入框**粘贴完整地址文字**（省市区 + 详细地址 + 联系人 + 电话写在一起），系统会自动拆分回填。识别失败可手动逐个填写。

### Q4：车长车型只能选固定的几种吗？
**答**：微信端目前开放**2/5/10 车型**与 **9.6m/16.5m 车长**，如需其他车型请联系业务人员通过货主端/平台端下单。

### Q5：下单后在哪看进度？
**答**：微信端无登录，下单后需：
- 联系发货方/货主，用订单号在**货主端**（[usr-02](./usr-02-货主端操作手册.md)）查询进度；
- 或让平台调度在平台端查询。

### Q6：要回单吗？
**页面操作**：第 3 步有"回单"开关，开启表示需要签收回单（收货方签收凭证）。

### Q7：含税怎么填？
**页面操作**：开启"含税"开关后需填写**公司名称**（开票抬头），结算价视为含税价。

### Q8：手机端适配有问题？
**答**：微信端按移动端适配（禁止缩放、Vant 组件），建议在微信内打开；如页面异常请清理微信缓存后重试。

## 二、各端常见问题（FAQ）

### 2.1 登录相关

**Q9：登录提示"账号或密码错误"？**
**答**：确认账号正确、大小写；连续输错会触发图形验证码；仍失败可走短信验证码登录或联系管理员重置。

**Q10：手机收不到验证码？**
**答**：确认手机号与账号绑定一致；检查短信拦截；60 秒内不要重复点击发送；仍失败联系管理员。

**Q11：登录后页面空白/一直转圈？**
**答**：多为缓存或网络问题。清理浏览器缓存，强制刷新（Ctrl+F5），或更换浏览器（建议 Chrome）。

### 2.2 数据与权限

**Q12：查不到某个订单/数据？**
**答**：可能原因：① 数据不在你的权限范围（组织/仓库/公司）；② 时间范围选错；③ 数据已删除或状态已变化。建议先放大时间范围、确认权限后重查。

**Q13：看不到某个菜单/按钮？**
**答**：菜单/按钮由后台权限（`v-entity`）控制，无权限即不显示。需要开通权限请联系管理员。

**Q14：库存数量不对？**
**答**：先确认仓库选择与时间点；库存按物料/储位两个维度看；出入库刚发生可能未刷新，重新查询。

### 2.3 订单与流程

**Q15：订单一直停在"待调度"？**
**答**：待调度=订单已提交、平台尚未派车。请联系平台调度查看处理；订单量大时排队属正常。

**Q16：订单能修改吗？**
**答**：未派车的订单可直接修改/取消；已派车/运输中需联系调度处理。

**Q17：怎么查订单进度？**
**答**：订单管理 → 详情 → 操作日志时间线（下单→派车→出车→到达→签收），AI 助手也可以帮你查。

**Q18：回单迟迟没有？**
**答**：回单在收货方签收后生成，需司机/收货方完成签收；确认已签收仍无回单，联系平台核查。

### 2.4 财务

**Q19：账单金额不对？**
**答**：先在未确认账单查看**明细**（仓储/配送/其他费用分项）；有疑问**不要确认**，联系财务核对后再确认。

**Q20：确认账单后还能改吗？**
**答**：前端不支持撤回确认，需联系平台财务处理。

### 2.5 大学端

**Q21：考试交卷了没成绩？**
**答**：客观题自动出分；含简答题需老师批阅后出完整成绩。

**Q22：课程打不开？**
**答**：确认课程已发布且指派到你的班级/岗位；个别课件格式建议用 Chrome 打开。

### 2.6 系统与安全

**Q23：页面提示"登录已过期"？**
**答**：会话 4 小时过期，重新登录即可；勾选"记住登录"可保持 7 天。

**Q24：浏览器打开是 http 被跳转？**
**答**：生产环境会强制跳转 https 保证安全，属正常现象。

**Q25：怀疑数据被误改？**
**答**：系统有操作日志，管理员可在系统日志中查操作记录（谁、何时、做了什么），用于核查与审计。

## 四、联系与升级

| 事项 | 方式 |
|------|------|
| 账号/权限问题 | 联系系统管理员 |
| 订单/运输问题 | 联系平台调度/客服 |
| 账单/结算问题 | 联系财务 |
| 系统报错/Bug | 提供报错截图 + 操作步骤，反馈给技术人员 |
