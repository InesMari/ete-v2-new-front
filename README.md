# EDB - 企业数字化管理平台

## 项目概述

EDB 是一个综合性的企业数字化管理平台，采用多租户架构设计，为不同类型的用户提供定制化的功能模块。系统包含平台端、货主端、易迁易大学和微信公众号等多个入口，涵盖了从订单处理、仓库管理、采购、财务到人力资源的多个业务领域。

## 系统架构

### 多租户架构

系统采用多租户设计，包含以下主要入口：

- **平台端 (pt)**: 管理员和运营人员使用的主要界面，包含系统的核心功能
- **货主端 (hz)**: 为货主（客户）提供的专用界面
- **易迁易大学 (edu)**: 培训和学习平台
- **微信公众号 (wx)**: 移动端微信公众号入口

### 核心功能模块

平台端包含以下主要功能模块：

- **基础数据管理 (base)**: 系统基础配置和数据管理
- **业务管理 (biz)**: 核心业务流程管理
- **客户管理 (cm)**: 客户信息和关系管理
- **数据报表 (dataReport)**: 数据分析和报表生成
- **设备管理 (device)**: 设备监控和管理
- **财务管理 (fc)**: 财务流程和账务管理
- **人力资源 (hr)**: 员工和组织管理
- **订单管理 (ord)**: 订单处理和跟踪
- **项目管理 (proj)**: 项目规划和执行
- **采购管理 (purchase)**: 采购申请和审批
- **资源管理 (res)**: 资源分配和调度
- **供应商管理 (sp)**: 供应商信息和关系管理
- **仓库管理 (wms)**: 库存和仓储管理

## 技术栈

### 前端

- **框架**: Vue.js 2.6.10
- **路由**: Vue Router 3.1.3
- **状态管理**: Vuex 3.1.1
- **UI 框架**: 
  - Element UI 2.15.14 (PC端)
  - Vant 2.12.54 (移动端)
- **HTTP 客户端**: Axios
- **图表库**: ECharts 4.9.0, Highcharts 9.1.1
- **地图组件**: Vue Baidu Map
- **富文本编辑器**: WangEditor 5.1.23
- **其他工具库**: 
  - JSEncrypt (RSA加密)
  - html2canvas (页面截图)
  - xlsx (Excel处理)
  - print-js (打印功能)
  - decimal.js (精确数学计算)

### 开发工具

- **构建工具**: Vue CLI 4.0.0
- **代码检查**: ESLint
- **CSS 预处理器**: Sass

## 安装与使用

### 环境要求

- Node.js (建议 v12.x 或更高版本)
- npm 或 yarn

### 安装依赖

```bash
# 使用 npm
npm install

# 或使用 yarn
yarn install
```

### 开发环境运行

```bash
# 使用 npm
npm run serve

# 或使用 yarn
yarn serve
```

### 生产环境构建

```bash
# 使用 npm
npm run build

# 或使用 yarn
yarn build
```

### 代码检查

```bash
# 使用 npm
npm run lint

# 或使用 yarn
yarn lint
```

## 待办事项系统

系统包含一个综合的待办事项功能，涵盖以下业务类型：

- **费用管理**: 供应商报价、客户报价、费用审核等
- **订单管理**: 客户订单处理、区域协同订单等
- **账单管理**: 账单审核、开票申请、付款申请等
- **采购管理**: 采购申请、物品领用、固定资产调拨等
- **其他功能**: 运力计划匹配、询价审计、合同评审等

## 安全特性

- 用户认证和授权
- RSA 加密敏感数据
- HTTP 到 HTTPS 的重定向
- 会话超时检测
